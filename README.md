MSLM (Multi-Scope Local Memory) 是一个本地优先的 AI Agent 多层次记忆系统。基于 SuperLocalMemory 引擎构建，为 Claude Code、Cursor、Hermes Agent 等 MCP 兼容客户端提供持久化记忆。

**核心特性**：三层作用域记忆（personal / shared / global）、7 通道混合检索、全局实体共享、数学驱动（无需云端 LLM）。
