# MSLM — Multi-Scope Local Memory

> **让 AI 不再遗忘的多层次本地记忆系统**
>
> MSLM 为 Claude Code、Cursor、Hermes Agent 等 AI 编程助手提供持久化记忆能力。
> 基于 SuperLocalMemory 引擎构建，增加多层次作用域、全局实体共享等协作特性。
